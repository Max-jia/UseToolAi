Grok Imagine 2.0 shipped August 7 as the default Quality Mode across Grok's apps — an editing-first image model that immediately landed at #2 on the public Text-to-Image Arena (Elo 1,320, preliminary), behind only GPT Image 2 and ahead of Google's Nano Banana 2. That ranking is notable because it's a public, human-vote arena — the same kind of data this site trusts over vendor marketing. The caveat, of course, is the word "preliminary": Elo shifts as votes accumulate.

The editing story is where Grok Imagine differentiates. Magic Wand, segmentation, background removal, and multi-reference input make it a tool for working on existing images, not just generating from prompts — a practical workflow for mockups, product shots, and design iteration. And the pricing model is refreshingly simple: a flat per-image fee ($0.02 standard, $0.05 quality) regardless of prompt length, versus token-based rivals like GPT Image 2 whose cost swings roughly 35x depending on quality and resolution.

One conflict we verified and can't fully resolve: xAI's official API docs list the model with pricing, but launch coverage states developer API access is "coming soon" with the 2.0 model ID unconfirmed. If you plan to build on it, verify availability and the model ID directly with xAI before committing. For consumer use, the gate is simpler: SuperGrok at $30/month, since the free tier was removed earlier in 2026. Pricing checked August 10, 2026.
